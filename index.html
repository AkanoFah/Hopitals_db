Hospital SQL Workbench

สคริปต์ SQL ของระบบฐานข้อมูลสำหรับการจัดการโรงพยาบาล สร้างตาราง ใส่ข้อมูลตัวอย่าง และทดสอบคำสั่งทีละขั้นได้ในหน้านี้

กำลังเตรียมฐานข้อมูล…

ต้องมี MySQL 8.0.16 ขึ้นไปรันอยู่ และติดตั้งไดรเวอร์ด้วย pip install pymysql · ถ้ายังไม่มีฐานข้อมูลชื่อนี้ ระบบจะสร้างให้ · ปุ่ม “สร้างฐานข้อมูลครบชุด” และ “เริ่มจากฐานข้อมูลว่าง” จะลบตารางทั้งหมดในฐานข้อมูลนี้ก่อน จึงควรใช้ชื่อฐานข้อมูลที่ไม่มีข้อมูลสำคัญ

Ctrl + Enter เพื่อรัน

โครงสร้างที่อ่านจากฐานข้อมูลที่กำลังใช้งานอยู่จริง กดปุ่ม “ดูข้อมูล” เพื่อเปิดข้อมูลในตารางนั้น หรือ “ลบ” เพื่อรีเซ็ตตารางนั้น (ตารางที่อ้างอิงอยู่จะถูกลบด้วย)

ชุด “MySQL” ใช้คำสั่งตารางและข้อมูลชุดเดียวกับที่ทดสอบบน SQLite เพิ่มการสร้างฐานข้อมูล hospital_db และตั้งรหัสอักขระ utf8mb4 สำหรับภาษาไทย ต้องใช้ MySQL 8.0.16 ขึ้นไป ยังไม่ได้ทดสอบบน MySQL จริง คำสั่งที่ตั้งใจให้เกิด error ถูกคอมเมนต์ไว้เพื่อให้รันทั้งไฟล์ได้
