Hospital SQL Workbench (รันในเครื่องตัวเอง)
=================================================

สิ่งที่ต้องมี: Python 3.8 ขึ้นไป (ดาวน์โหลดที่ https://www.python.org/downloads/
ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH") โหมด SQLite ไม่ต้องติดตั้งแพ็กเกจเพิ่ม
(โหมด MySQL ต้องติดตั้ง pymysql ดูหัวข้อ "รันด้วย MySQL") และไม่ต้องต่ออินเทอร์เน็ต (ถ้าไม่มีอินเทอร์เน็ต ฟอนต์จะเป็นฟอนต์ของเครื่อง)

วิธีเปิด
  Windows : ดับเบิลคลิก run.bat
  Mac/Linux: เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์  sh run.sh
  หรือทุกระบบ: พิมพ์  python app.py  (หรือ python3 app.py)

เบราว์เซอร์จะเปิดหน้าเว็บขึ้นมาเอง ถ้าไม่เปิด ให้เปิดลิงก์ที่ขึ้นใน
หน้าต่างดำ (ปกติคือ http://127.0.0.1:8000/)
ปิดโปรแกรมด้วยการปิดหน้าต่างดำ หรือกด Ctrl+C

ข้อควรรู้
  - ค่าเริ่มต้นรันบน SQLite ที่มากับ Python ฐานข้อมูลอยู่ในหน่วยความจำ
    ปิดโปรแกรมหรือกด "สร้างฐานข้อมูลครบชุด" แล้วกลับเป็นค่าเริ่มต้น
  - โปรแกรมเปิดรับเฉพาะเครื่องนี้ (127.0.0.1) เครื่องอื่นต่อเข้ามาไม่ได้
  - ถ้าพอร์ต 8000 ถูกใช้อยู่ โปรแกรมจะเลือกพอร์ตถัดไปให้เอง

รันด้วย MySQL
  1) ติดตั้งไดรเวอร์ครั้งเดียว:  pip install pymysql   (หรือ pip install -r requirements.txt)
  2) ต้องมี MySQL 8.0.16 ขึ้นไปเปิดอยู่ในเครื่อง (หรือเครื่องอื่นที่ต่อถึง)
  3) เปิดโปรแกรมตามปกติ แล้วเลือก "เอนจิน" เป็น MySQL ที่มุมขวาบน
     กรอก Host / Port / User / Password / ชื่อฐานข้อมูล แล้วกด "เชื่อมต่อ MySQL"
     (ถ้ายังไม่มีฐานข้อมูลชื่อนี้ ระบบจะสร้างให้ด้วย utf8mb4)
  4) กด "สร้างฐานข้อมูลครบชุด" หรือรันทีละขั้นตอนได้เหมือนกับ SQLite
  - ตารางบน MySQL เป็นของจริง ปิดโปรแกรมแล้วข้อมูลยังอยู่
  - "สร้างฐานข้อมูลครบชุด" และ "เริ่มจากฐานข้อมูลว่าง" จะลบตารางและ view ทั้งหมดใน
    ฐานข้อมูลที่เชื่อมต่ออยู่ก่อน (มีหน้าต่างถามยืนยัน) ควรใช้ชื่อฐานข้อมูลที่ไม่มีข้อมูลสำคัญ
  - เลือกเอนจินกลับเป็น SQLite ได้ทุกเมื่อ

ปุ่มลบตาราง (รีเซ็ตทีละตาราง)
  - ในกลุ่ม "สร้างฐานข้อมูล (DDL)" แต่ละขั้นตอนจะมีปุ่มสีแดง เช่น "ลบตาราง ROOM_TYPE"
    กดแล้วลบสิ่งที่ขั้นตอนนั้นสร้างไว้ เพื่อแก้คำสั่งแล้วกด "รันคำสั่ง" ใหม่ได้
  - ถ้ามีตารางอื่นอ้างอิงอยู่ (Foreign Key) หรือมี view ที่ใช้ตารางนั้น จะมีหน้าต่างถามยืนยัน
    และลบตารางที่อ้างอิงให้ตามลำดับ (ตารางลูกก่อนตารางแม่) พร้อมรีเซ็ตสถานะขั้นตอนที่เกี่ยวข้อง
  - แท็บ "โครงสร้างตาราง" มีปุ่ม "ลบตาราง" ที่การ์ดของทุกตารางด้วย

ไฟล์ในโฟลเดอร์
  app.py                 ตัวโปรแกรม (เซิร์ฟเวอร์ + ตัวรัน SQL ทั้ง SQLite และ MySQL)
  index.html             หน้าเว็บ
  hospital_db.sql        สคริปต์ชุดเต็มสำหรับ SQLite
  hospital_db_mysql.sql  สคริปต์ชุดเต็มสำหรับ MySQL 8.0.16 ขึ้นไป
  requirements.txt       แพ็กเกจที่ต้องติดตั้งเพิ่มเมื่อจะใช้ MySQL (pymysql)
